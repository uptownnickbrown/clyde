# Decisions

The distilled rulings from resolved discussions. The argument may compact away; the ruling survives. Never re-litigate an entry without acknowledging it.

Two line kinds, both rulings: `- Decided: <what> because <why> (<date>)` — a settled call; `- Deferred: <axis> — revisit when <trigger> (<date>)` — a posture deferral, the decision NOT to build for an axis yet. Deferrals carry a distinct prefix so tripwire machinery (v2) and the Decisions panel can match them.
